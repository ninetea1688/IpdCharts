# IPD Domain Skill — ระบบยืม-คืนเวชระเบียนผู้ป่วยใน

> แหล่งอ้างอิง: [prd/prd.md](../../../prd/prd.md) (เวอร์ชัน 1.0)
> ถ้าโดเมนเปลี่ยน ต้องอัปเดตไฟล์นี้ + `AGENTS.md` + `.opencode/memory/glossary.md` พร้อมกัน

## Entities (หลัก)

| Entity | ชื่อไทย | รายละเอียด |
|---|---|---|
| `MedicalRecord` | แฟ้มเวชระเบียน | มี **barcode = เลข HN** (Hospital Number) ของผู้ป่วย — identifier หลัก |
| `Borrow` | การยืม | บันทึกการยืม 1 ครั้ง ต่อ 1 แฟ้ม (บังคับ: ผู้ยืม + หน่วยงาน + เหตุผล + กำหนดคืน) |
| `User` | ผู้ใช้ | บุคลากรในโรงพยาบาล มีบทบาท (role) กำหนดสิทธิ์ |
| `Department` | หน่วยงาน | หอผู้ป่วย/แผนกที่ยืมแฟ้ม |
| `AuditLog` | บันทึกเหตุการณ์ | ทุก action (ยืม/คืน/แก้) ต้องบันทึก: ใคร, เมื่อไหร่, ทำอะไร (PDPA) |

## State Machine (สถานะแฟ้ม)

```
available ──borrow──▶ borrowed ──return──▶ returned
   ▲                    │
   └────── return ──────┘
```

| สถานะ | เงื่อนไข |
|---|---|
| `available` | แฟ้มอยู่ที่เวชระเบียน — ยืมได้ |
| `borrowed` | ถูกยืมไปแล้ว — ยืมซ้ำไม่ได้ (ต้องรอคืน) |
| `overdue` | สถานะ**คำนวณ**จาก borrowed + ผ่าน dueDate + 7 วัน (ตาม PRD) — ไม่ใช่สถานะที่บันทึกเอง |
| `returned` | คืนแล้ว — กลับสู่ available ได้ใหม่ |

> หมายเหตุ: `overdue` เป็น derived status — คำนวณตอน query โดยเทียบ `now > dueDate + 7 วัน` ไม่ต้องมีคอลัมน์แยก (หรือมี field สำหรับ cache ก็ได้ แต่ต้อง sync)

## นโยบาย (Business Policies)

1. **การยืม (Borrow)** — ต้องมีครบ: ผู้ยืม, หน่วยงาน, เหตุผล, `dueDate` (กำหนดคืน)
   - ยืมแฟ้มที่ไม่อยู่ (`borrowed`/`overdue`) → **ปฏิเสธ** พร้อม error ภาษาไทย
2. **การคืน (Return)** — แฟ้มต้องถูกยืมอยู่จริง (`borrowed`) ถึงจะคืนได้
   - คืนผิดคน/แฟ้มไม่ตรงกับรายการยืม → **ปฏิเสธ**
3. **การแจ้งเตือน (Alert)**:
   - เตือนก่อนครบกำหนด (ใกล้ dueDate)
   - เตือนเมื่อเกินกำหนด (overdue) — ตามนโยบาย dueDate + 7 วัน
4. **การค้นหา** — ค้นหาด้วย barcode/HN ได้ผลลัพธ์ใน < 10 วินาที (เป้าหมาย PRD)
5. **RBAC** — ตรวจสิทธิ์ที่ server ทุก request:
   - `admin` (เจ้าหน้าที่เวชระเบียน): จัดการทั้งหมด, แก้/ลบ, ดูรายงาน
   - `borrower` (แพทย์/พยาบาล): ยืม/คืนของตนเอง, ดูสถานะ
   - `department_head` (หัวหน้าหน่วยงาน): ดูรายงาน/สถิติของหน่วยงาน

## กติกาทั่วไป

- **Time zone**: เก็บ UTC ใน DB, แปลงเป็น `Asia/Bangkok` ตอนแสดงผล
- **เลข HN**: ตัวเลขเท่านั้น (format ตามโรงพยาบาล) — barcode scan ได้เลย
- **ภาษา UI**: ไทย (ปุ่ม, label, error, toast) — ชื่อโค้ดเป็นอังกฤษ
- **PDPA**: ข้อมูลผู้ป่วย (ชื่อ, HN, วินิจฉัย) ห้ามอยู่ใน commit/PR/screenshot

## คำศัพท์ที่ใช้ในโค้ด (Mapping)

| ในโค้ด (อังกฤษ) | UI (ไทย) |
|---|---|
| `borrow` / `return` | ยืม / คืน |
| `dueDate` | กำหนดคืน |
| `overdue` | เกินกำหนด |
| `available` | พร้อมยืม / อยู่เวชระเบียน |
| `medicalRecord` | แฟ้มเวชระเบียน |
| `barcode` / `hn` | เลข HN |
