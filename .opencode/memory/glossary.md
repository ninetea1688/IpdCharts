# Glossary — IpdCharts

> ศัพท์โดเมนมาตรฐาน — ใช้ให้ตรงกันทั้งโค้ด เอกสาร และ UI
> แหล่งอ้างอิง: PRD v1.0 + skill `ipd-domain`

| คำ (ไทย) | คำในโค้ด (อังกฤษ) | คำนิยาม |
|---|---|---|
| แฟ้มเวชระเบียน | `MedicalRecord` | แฟ้มประวัติผู้ป่วยใน (IPD) ที่ให้ยืม-คืน |
| เลข HN | `hn` / `barcode` | เลขประจำตัวผู้ป่วย (Hospital Number) — ใช้เป็น barcode |
| การยืม | `Borrow` | บันทึกการยืมแฟ้ม 1 ครั้ง: ผู้ยืม + หน่วยงาน + เหตุผล + กำหนดคืน |
| การคืน | `Return` | การส่งแฟ้มคืนหน่วยงานเวชระเบียน |
| ผู้ยืม | `Borrower` | แพทย์/พยาบาลที่ยืมแฟ้ม (role: `borrower`) |
| หน่วยงาน | `Department` | หอผู้ป่วย/แผนกที่ยืม (เช่น วิกฤติ, ศัลยกรรม) |
| กำหนดคืน | `dueDate` | วันที่ต้องคืนแฟ้ม — บังคับทุกการยืม |
| เกินกำหนด | `overdue` | แฟ้มที่ยังไม่คืนหลัง dueDate + 7 วัน (คำนวณอัตโนมัติ) |
| พร้อมยืม | `available` | แฟ้มอยู่ที่เวชระเบียน, ยืมได้ |
| อยู่ระหว่างยืม | `borrowed` | แฟ้มถูกยืมอยู่ — ยืมซ้ำไม่ได้ |
| คืนแล้ว | `returned` | แฟ้มคืนแล้ว |
| เจ้าหน้าที่เวชระเบียน | `admin` | ผู้ดูแลระบบ — จัดการทั้งหมด, แก้/ลบ, รายงาน |
| หัวหน้าหน่วยงาน | `department_head` | ดูรายงาน/สถิติของหน่วยงานตนเอง |
| บันทึกเหตุการณ์ | `AuditLog` | log ทุก action: ใคร, เมื่อไหร่, ทำอะไร (PDPA) |
| QR / Barcode | `scan` | วิธีระบุแฟ้ม — สแกนจากกล้องมือถือ/สแกนเนอร์ |
| Dashboard | `dashboard` | หน้าแสดงสถิติเรียลไทม์: ยืมอยู่, เกินกำหนด, คืนแล้ว |

## หลักการใช้
- อย่าสร้างคำศัพท์ใหม่ถ้ามีอยู่แล้วในตารางนี้
- ถ้าต้องเพิ่มคำ → อัปเดตตารางนี้ + skill `ipd-domain` พร้อมกัน
